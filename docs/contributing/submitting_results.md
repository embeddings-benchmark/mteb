# Submit Results

## Overview

The [`ResultCache`][mteb.cache.result_cache.ResultCache] class manages evaluation results locally and submits them to the [official results repository](https://github.com/embeddings-benchmark/results). Use it to cache results, avoid re-computation, and contribute results back to the community.

If you want to request that a model be evaluated, rather than submitting results that you ran yourself, open an [Evaluation Request](https://github.com/embeddings-benchmark/mteb/issues/new?template=eval_request.yaml) issue.

## Submission requirements

Before submitting results, check that your submission meets the requirements in the [results PR checklist](https://github.com/embeddings-benchmark/results/blob/main/.github/pull_request_template.md):

- The model has a model sheet, report, or similar documentation.
- The model is publicly available, either through an API or as downloadable weights.
- The model has a reference implementation in `mteb/models/model_implementations/`. If it has not been added yet, link the existing model PR in the results checklist. See [Adding a Model](./adding_a_model.md) for the implementation requirements and model PR checklist.
- The submitted results were obtained using that reference implementation.
- Disclose clearly if the model was trained on any evaluation dataset, including its training splits.

### Evaluation records

New results must satisfy the [results repository's validation checks](https://github.com/embeddings-benchmark/results/blob/main/tests/test_new_results_run_settings.py):

- Results must be produced with MTEB 2.0.0 or later and record a usable `mteb_version`.
- Include `run_settings.jsonl` alongside the results, covering every submitted task, split, and subset. Preserve the evaluation records generated by MTEB when preparing your submission.
- For models returning low-precision floating-point embeddings (such as float16 or bfloat16), scoring must use float32. The checks require MTEB 2.24.6 or later, or sentence-transformers 6.0.0 or later, as recorded in the run settings.

### Human review and AI assistance

Under the [MTEB AI Policy](https://github.com/embeddings-benchmark/mteb/discussions/4509), AI-assisted contributions are welcome, but a human contributor must review, understand, and take responsibility for the submission. A human contributor should complete PR checklists, model cards, and result submissions, especially the training-data integrity declaration. Disclose meaningful AI assistance in the PR description; minor autocomplete does not require disclosure.

## Quick Start

Complete example: evaluate, cache, and submit results:

=== "Python"

    ```python
    import mteb

    # 1. Initialize cache
    cache = mteb.ResultCache()

    # 2. Evaluate model
    model_meta = mteb.get_model_meta("sentence-transformers/all-MiniLM-L6-v2")
    task = mteb.get_task("ArguAna")

    mteb.evaluate(model_meta, task, cache=cache)

    # 3. Submit results
    cache.submit_results(model_meta, create_pr=False)  # manual review before pushing
    ```

=== "CLI"

    ```bash
    # 1. Evaluate model
    mteb run -m sentence-transformers/all-MiniLM-L6-v2 -t ArguAna

    # 2. Submit results
    mteb submit-results -m sentence-transformers/all-MiniLM-L6-v2 -t ArguAna  # manual review before pushing
    ```

Only results that the results repository does not have yet are submitted. Results computed on a different dataset revision than those in the repository are skipped with a warning.

## Submitting Results
=== "Manual Submission"
    !!! note Requirements
        Git is required for this action.

    Prepare results without automatically creating a PR:

    === "Python"

        ```python
        submission_info = cache.submit_results(
            models=["sentence-transformers/all-MiniLM-L6-v2"], create_pr=False
        )

        # submit_results logs the manual submission instructions
        print(f"Prepared submission at: {submission_info['path']}")
        ```

    === "CLI"

        ```bash
        # logs the manual submission instructions
        mteb submit-results -m sentence-transformers/all-MiniLM-L6-v2
        ```

=== "Automated Submission"
    !!! note Requirements
        Git, [GitHub CLI](https://cli.github.com) are required for this action. You also need to install the `mteb[github]` extra dependencies and configure GitHub integration by signing in with `gh auth login` or setting up your Git credential helper.

        === "pip"
            ```bash
            pip install mteb[github]
            ```
        === "uv"
            ```bash
            uv pip install mteb[github]
            ```
    Then run your code:

    === "Python"

        ```python
        submission_info = cache.submit_results(
            models=["sentence-transformers/all-MiniLM-L6-v2"],
            create_pr=True,
            message="Add ArguAna results for all-MiniLM-L6-v2",
        )

        if submission_info.get("pr_url"):
            print(f"PR created: {submission_info['pr_url']}")
        ```

    === "CLI"

        ```bash
        mteb submit-results -m sentence-transformers/all-MiniLM-L6-v2 \
            --create-pr \
            --message "Add ArguAna results for all-MiniLM-L6-v2"
        ```

    The message is used as the title of the commit and PR; if omitted, a title listing the submitted models is used.

### Batch Submission

Submit multiple models at once:

=== "Python"

    ```python
    models = [
        "sentence-transformers/all-MiniLM-L6-v2",
        "sentence-transformers/all-mpnet-base-v2",
        "BAAI/bge-base-en-v1.5",
    ]

    cache.submit_results(models=models, create_pr=False)
    ```

=== "CLI"

    ```bash
    mteb submit-results -m sentence-transformers/all-MiniLM-L6-v2 \
        sentence-transformers/all-mpnet-base-v2 \
        BAAI/bge-base-en-v1.5

    # without -m, the results of all models are submitted
    mteb submit-results
    ```

You can also restrict the submission to specific tasks with `tasks=[...]` in Python or `-t` in the CLI.


### After submission

Once the PR is created, your results will wait for review; we aim for this to take less than a week. To speed up the review, please fill out the [results PR checklist](https://github.com/embeddings-benchmark/results/blob/main/.github/pull_request_template.md). During the review process we might ask you about suspicious results or ask you to check for potential data leakage.
